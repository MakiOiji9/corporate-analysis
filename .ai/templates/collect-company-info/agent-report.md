# 担当報告の形式（サブエージェント → 親）

> 担当（collect-ir / collect-filings / collect-market / collect-peers-valuation）は作業の最後に、この形式で**返答として**報告する（ファイルには保存しない）。
> 親はこれを `status.md`・`overview.md`・完了報告に集約する。報告は事実だけを書き、評価・判定は書かない。
