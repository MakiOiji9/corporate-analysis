# companies/ — 企業個別分析

銘柄ごとの詳細分析を格納するディレクトリです。

## ディレクトリ命名規則

`{ticker}_{name}/`　例: `7203_toyota`, `9984_softbank`, `AAPL_apple`

## 企業ディレクトリの構造

`/new-company {ticker} {name}` で以下の雛形が自動生成されます。

```
{ticker}_{name}/
├── overview.md          # 企業概要・投資テーゼ・ウォッチリスト状態
├── raw/                 # 生データ（収集後は変更禁止）
│   ├── ir/              # 決算資料・IR資料・中期経営計画
│   ├── filings/         # 有価証券報告書(EDINET) / 10-K(SEC EDGAR)
│   └── news/            # ニュース・プレスリリース
├── sessions/            # 日付付き分析セッション
│   └── YYYY-MM-DD_{topic}/
│       ├── step1/       # STEP1: 事業・競争環境分析
│       ├── step2/       # STEP2: 財務分析
│       ├── step3/       # STEP3: バリュエーション
│       └── judgment-sheet.md
└── reports/             # 完成した投資レポート
```

## 3STEP分析フロー

企業分析フレームワーク.md に従い、以下の順で実行します。

| STEP | 観点 | 問い | C判定なら |
|---|---|---|---|
| 1 | 事業・競争環境 | 良いビジネスか | その時点で終了 |
| 2 | 財務 | 数字が裏付けているか | その時点で終了 |
| 3 | バリュエーション | 今の株価は妥当か | — |

## 情報源

- **日本株**: EDINET（有価証券報告書）、決算短信、IR資料
- **米国株**: SEC EDGAR（10-K/10-Q）、決算リリース
- **共通**: 証券会社ツール、業界団体統計、競合のIR資料
