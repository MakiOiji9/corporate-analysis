# 提案: 投資の質の分析（「何に投資したか」を企業分析レポートに追加）

実装前にレビューを受けるための提案書。2026-11-23 に段階1〜4を実装した（BL-38）。決まったことは「2. 決定事項」、まだ決めていないことは「9. 未決事項」に書く。

## 1. 目的

- 会社が**何に**投資したか（設備・研究開発・M&A・出資）を、過去10年の推移とともに企業分析レポートで見られるようにする。特に**どこで変化したか**を示す。
- 投資の質に判定を付け、企業分析レポートの点数に反映する。
- 評価の切り口: 投資効率、中期経営計画との整合、世界の潮流との整合、競合比較、および追加の8項目（6章）。

## 2. 決定事項（2026-11-23 時点）

| 項目 | 決定 |
|---|---|
| スキルの形 | 独立した新スキル `investment`（投資の質）。成長性分析とは別 |
| 判定 | 投資の質 良好 / 普通 / 懸念（材料不足なら 判定保留）を付ける |
| 点数 | 案1: 長期に 10（成長性 20→15、3C 15→10）、中期に 5（成長性 15→10） |
| 二重計上 | (i) 成長性の手順5（成長投資: 投資比率 × 増分 ROIC）は investment に移す。成長性は investment の結果を引用するだけにし、成長性の判定には入れない |
| 世界の潮流の材料 | 今ある材料だけ（`raw/market` の業界の構造変化要因、中期経営計画、地合いの政策文書の要旨）。web 検索は足さない |
| 競合比較 | 数値だけ（設備投資・研究開発費・成長投資の売上比を同業中央値と比べる）。競合の投資内容は集めない |
| 米国株 | 出せる範囲でよい（金額は companyfacts、内容は 10-K の本文から） |
| 過去の情報 | 最大10期（collect-filings が既に取る有報 XBRL の範囲）で推移を見る |
| 追加の評価 | 6章の (a)〜(h) をすべて入れる |
| レポートの置き場 | 既存の「成長投資の推移」の直後 |

## 3. 現状

- `xbrl_financials.py` / `edgar.py` が設備投資（有形・無形）・減価償却費・研究開発費・子会社の取得・のれん・無形資産を `data/financials.csv` に取り込んでいる。
- 成長性分析の手順5（`tools/analysis/gr_invest.py`）が「成長投資 = 設備投資 − 減価償却費 ＋ 研究開発費 ＋ 運転資本の増加 ＋ 子会社の取得」の売上比と増分 ROIC から判定し、レポートに「成長投資の推移」の表がある（`tools/report/cr_sections.py`）。**分かるのは「いくら」まで**。
- 「何に」は最新の有報1期の要約（`raw/filings/*_yuho.md` の2章・6章・7章）に文章であるだけで、レポートには出ていない。過去の期の内容は無い。
- 競合は collect-peers-valuation の14章で、設備投資・減価償却費・研究開発費を最大5期集めている。

## 4. 収集

collect-filings が取得済みの過去10期の有報 XBRL→CSV（`sources/`）から、追加ダウンロードなしで抜き出し、`data/investments.json` に書く（`yuho_governance.py` と同じ作り。`data/` はスクリプト専用で手書き禁止）。

## 5. 分析: スキル `investment`

他の分析と同じ分担: **数値・変化点・判定は Python（`tools/analysis/investment.py`）**、LLM は投資内容の分類（テーマ）・変化の背景・潮流との照合の根拠だけを書く。手順は 企業の選択 → 鮮度確認 → 準備 → 執筆 → ビルド。

成果物: `companies/{ticker}_{name}/analysis/investment/{日付}_investment.md`・`.json`・`_brief.md`。

### 5.1 何に投資したか（年ごとの表）

年ごとに、設備投資額とセグメント別の配分、主な内容（LLM が有報の文章から1行で要約。出典の期とページを付ける）、研究開発費と主なテーマ、M&A（相手先・取得額）、減損、政策保有株の増減を並べる。

### 5.2 変化点（Python が抽出）

次のどれかに当たる年に印を付け、LLM がその年の背景を有報・中計・決算資料から書く（見つからなければ「会社の説明なし」）。

| 変化点 | 条件（案） |
|---|---|
| 投資の急増・急減 | 設備投資 ÷ 売上が、前3年の平均の 1.5倍以上 / 0.5倍以下 |
| 配分の変化 | セグメント別の設備投資の構成比が、前年から 10ポイント以上動いた |
| 研究開発の変化 | 研究開発費 ÷ 売上が、前3年の平均から 1ポイント以上動いた |
| M&A | 子会社の取得による支出が売上の 5%以上、または企業結合の注記がある年 |
| 新しい投資テーマ | LLM が分類したテーマが、その年に初めて出た（Python がテーマの一覧の差分で判定） |
| 局面の切り替わり | 設備投資 ÷ 減価償却費が 1倍をまたいだ（攻め ↔ 守り）年 |

### 5.3 評価の軸

| 軸 | 見ること | 結果 |
|---|---|---|
| ① 投資効率 | 成長性の手順5の増分 ROIC（そのまま移す）。(c) 有形固定資産回転率の推移。多く配分したセグメントで、売上と利益率が上がったか | 良好 / 普通 / 問題あり / 不明 |
| ② 中期経営計画との整合 | 中計の投資額・重点分野と実際の配分の差。前年の「設備の新設計画」が予定どおり完了したか（延期・中止・金額の膨張） | 整合 / 一部 / 乖離 / 不明 |
| ③ 世界の潮流との整合 | LLM が付けた投資テーマを、`raw/market` の業界の構造変化要因と地合いの政策文書の要旨に照らす。テーマごとに出典を書き、出典の無い照合は「不明」 | 合う / 一部 / 逆行 / 不明 |
| ④ 競合比較 | 設備投資・研究開発費・成長投資の売上比を同業中央値と比べる（成長性の手順5の投資比率もここに移す） | 高い / 同等 / 低い / 不明 |
| ⑤ 失敗の履歴 | (a) 減損の履歴、(b) のれん ÷ 純資産 | 問題なし / 注意 / 問題あり |
| ⑥ 資金と規律 | (d) 建設仮勘定、(e) 局面、(f) 資金源、(g) 重点テーマの継続性、(h) 政策保有株の増減 | 問題なし / 注意 / 問題あり |

### 5.4 判定（案）

保守的判断（policy 6）に従い、迷うときは低い方を採る。

- **懸念**: ① が 問題あり、または ⑤ が 問題あり、または ⑥ が 問題あり
- **良好**: ① が 良好、かつ ② が 整合 または 一部、かつ ③ が 合う または 一部、かつ ⑤・⑥ に 問題あり が無い
- **普通**: 上のどちらでもない
- **判定保留**: ① が 不明、かつ ②〜④ の半分以上が 不明（判定に使える事実が足りない）
- ④ の「低い」は、① が良好でも 普通 に下げる（投資しないことで利益率を保っている可能性。今の成長性の手順5の「比率 低い → 普通」と同じ）

## 6. 追加の評価 (a)〜(h) のしきい値（案）

| 項目 | 指標 | 注意 | 問題あり |
|---|---|---|---|
| (a) 減損の履歴 | 直近5年の減損損失の累計 ÷ 直近の純資産 | 5%以上 | 10%以上、または のれんの減損が2回以上 |
| (b) のれん | のれん ÷ 純資産 | 30%以上 | 50%以上、かつ (a) で減損あり |
| (c) 有形固定資産回転率 | 売上 ÷ 有形固定資産。5年の傾き | 3年続けて低下 | 5年続けて低下、かつ利益率も低下 |
| (d) 建設仮勘定 | 建設仮勘定 ÷ 有形固定資産 | 前3年の平均の2倍以上 | 2倍以上が3年続く（立ち上がりの遅れ） |
| (e) 局面 | 設備投資 ÷ 減価償却費 | 3年続けて 0.8倍未満（投資不足。今の成長性の「投資不足」と同じ扱い） | — |
| (f) 資金源 | 5年の投資の合計のうち、営業CF で賄えなかった分の割合 | 30%以上 | 50%以上、かつ ① が 普通以下 |
| (g) テーマの継続性 | 毎年の重点テーマのうち、前年からの継続の割合（LLM の分類を Python が集計） | 50%未満の年が2回以上 | — |
| (h) 政策保有株 | 政策保有株の計上額 ÷ 純資産と増減 | 10%以上で増加 | 20%以上で増加 |

## 7. 企業分析レポート

- 「成長投資の推移」の表の直後に「何に投資したか」の節を置く。年ごとの表（5.1）に変化点（5.2）の印、評価の軸（5.3）の表、判定と根拠。
- 点数: `tools/report/cr_judge.py` の `WEIGHTS` に `investment` を足す（2章の案1）。
- `/company-report` の実行順: growth の前に investment を入れる（five-forces → three-c → moat → swot → profitability → **investment** → growth → safety → cash-flow → valuation）。growth が investment の結果を引用するため。

## 8. 既存への影響

- 成長性の判定から手順5が外れるため、**既存4社の成長性の判定が変わりうる**。investment を作ったあと growth を作り直す。
- 成長性分析のスキル文書・`gr_invest.py`・テスト、`cr_sections.py` の成長投資の表、CLAUDE.md のスキル一覧とコマンドの説明を更新する。
- 既存4社は、過去の有報の文章を取り込むために `collect-company-info mode=update`（`yuho_investments.py` の実行）が要る。
