# market/ — 地合い分析

マクロ経済・国の方針・政治情報を統合し、株式市場の地合いを判断するディレクトリです。

## 目的

トップダウン分析の起点として、以下を評価します。

- 金融政策（日銀・FRB の方向性）
- 財政政策（政府の経済対策・予算方針）
- 政治動向（選挙・政権交代・規制変化）
- マクロ指標（CPI・GDP・金利・為替）

## ワークフロー

1. `@market-analyst` エージェントを起動
2. セッションディレクトリを作成: `/new-session market {topic}`
3. `raw/` に情報を収集・貼り付け
4. エージェントが `analysis.md` と `outlook.md` を生成
5. 次回の企業分析前に最新の `outlook.md` を参照する

## セッションディレクトリ構造

```
sessions/YYYY-MM-DD_{topic}/
├── raw/
│   ├── boj-policy.md        # 日銀・金融政策
│   ├── fiscal-policy.md     # 政府・財政政策
│   └── macro-indicators.md  # CPI・GDP・金利・為替
├── analysis.md              # マクロ要因の統合分析
└── outlook.md               # 地合い判断（強気/中立/慎重/弱気）
```

## 地合い判断の4段階

| 判断 | 意味 |
|---|---|
| 強気 | 複数のマクロ要因が追い風。積極的な新規投資を検討 |
| 中立 | 特段の追い風・逆風なし。個別銘柄の実力で判断 |
| 慎重 | 一部にリスク要因あり。ポジションを抑えめに |
| 弱気 | 複数のリスク要因が重なる。新規投資を控える |
